# Chapter 03 - Agentic AI Foundations

How to build a deterministic agent loop:
- understand intent
- decide action
- generate response

## Which Files To Open

- `app.py`
- `agentdesk_ai/agent.py`

## What Student Should Observe

- Structured JSON output.
- Intent and lead scoring driven by explicit rules.

## Common Mistakes

- Expecting LLM-generated text at this stage.
- Modifying scoring rules without testing sample messages.
