# Chapter 09 - Lead Follow-Up

## What This Chapter Teaches

How to add structured lead follow-up planning based on intent and lead score.

Prerequisite: complete one-time setup in `chapter_02_project_setup`.

## Which Files To Open

- `agentdesk_ai/tools.py`
- `agentdesk_ai/agent.py`
- `app.py`

## What Command To Run

```bash
python app.py
```

## What Student Should Observe

- Output includes a follow-up plan.
- High-score leads receive clearer next steps.

## Common Mistakes

- Treating support complaints as sales opportunities.
- Missing contact collection steps for demo-qualified leads.
