# Chapter 08 - Guardrails and Escalation

## What This Chapter Teaches

How to harden agent behavior with risk-aware escalation and stricter response constraints.

Prerequisite: complete one-time setup in `chapter_02_project_setup`.

## Which Files To Open

- `agentdesk_ai/tools.py`
- `agentdesk_ai/agent.py`

## What Command To Run

```bash
python app.py
```

## What Student Should Observe

- Sensitive issues escalate more reliably.
- Prompt safety rules prevent unsupported claims.

## Common Mistakes

- Over-aggressive escalation on every message.
- Weak escalation keywords that miss payment-related pain.
