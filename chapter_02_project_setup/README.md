# Chapter 02 - Project Setup

## What This Chapter Teaches

You set up the Python project and run a basic terminal app loop.

## Which Files To Open

- `app.py`
- `agentdesk_ai/agent.py`
- `.env.example`
- `requirements.txt`

## What Command To Run

```bash
pip install -r requirements.txt
python app.py
```

## What Student Should Observe

- Terminal app starts successfully.
- Message loop accepts user input and returns a placeholder JSON response.

## Common Mistakes

- Running commands outside this chapter folder.
- Forgetting to install dependencies.

## Connection To Next Chapter

Next chapter upgrades placeholder logic into an agentic loop (intent, decision, response).
